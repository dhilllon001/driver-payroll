# Driver Payroll

Redesign of Charger Logistics trip processing / driver payroll UI using the **Accessorial Management** design tokens.

## Run

```bash
npm install
npm run dev
```

## What’s included

- **Trip Processing Board** — search, filters (payment / flag / role / tags), full trip table, pagination, export & upload actions
- **Trip Detail** — location history, events table, payment / extras / properties / documents / notes / IFTA tabs
- **Add Trip Payment** modal — driver, compensate, payroll date, tax code, pay adjustment, standard pay lines, notes
- **Trip Exception** modal — custom note, error exception, rule name
- Dark sidebar chrome + Accessorial Management surfaces, Inter typography, category accents

## Stack

React 19 · Vite · TypeScript · Lucide icons
